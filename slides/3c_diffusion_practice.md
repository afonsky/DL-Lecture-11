# One Diffusion Training Step: Predict the Added Noise

<div class="grid grid-cols-[1fr_1fr] gap-7">
<div>

```python
t = torch.randint(0, T, (x0.shape[0],), device=x0.device)
eps = torch.randn_like(x0)
ab = alpha_bar[t].view(-1, 1, 1, 1)

xt = ab.sqrt() * x0 + (1 - ab).sqrt() * eps
eps_pred = denoiser(xt, t)

loss = F.mse_loss(eps_pred, eps)
opt.zero_grad()
loss.backward()
opt.step()
```

Excerpt: `x0`, `alpha_bar`, `T`, `denoiser` and `opt` are supplied by the training program
</div>
<div>
<div class="rounded-lg p-4 bg-blue-50 dark:bg-blue-900">

### Input
#### noisy state `xt` + integer time `t`
</div>
<div class="rounded-lg p-4 bg-orange-50 dark:bg-orange-900 mt-3">

### Target
#### the **known noise** `eps`, with the same shape as `x0`
</div>
<div class="rounded-lg p-4 bg-green-50 dark:bg-green-900 mt-3">

### Generation
#### start from `xT ~ N(0,I)`; call the denoiser repeatedly with a sampler
</div>
</div>
</div>

<div class="mt-4 rounded p-3 text-center bg-yellow-50 dark:bg-yellow-900">

**Training needs one random noise level per example; generation needs a sequence of denoising steps.**
</div>

<span class="refs">Algorithm and objective: [Ho et al., DDPM](https://arxiv.org/abs/2006.11239) · MSE and the training loop: **See Lecture 2** · AdamW: **See Lecture 8**</span>

<!--
Two minutes. Read the code as sample a time, sample noise, corrupt, predict, regress. alpha_bar is indexed per batch example and reshaped for NCHW broadcasting. Both eps and eps_pred have x0's shape. The network also receives t so it can calibrate its prediction to the noise level.

Training can use independent noisy versions of a real example rather than literally simulating every Markov transition. At inference, start with Gaussian noise and use a sampler to choose and apply a sequence of updates; MSE training alone does not specify that sampler.

<!--
Ninety seconds. Pixel-space diffusion repeatedly processes the full image resolution. Latent diffusion first learns or reuses an autoencoder, performs the generative process in its compressed representation, then decodes once at the end.

The shape example uses spatial downsampling by 8 and four latent channels: 512×512×3 = 786,432 values against 64×64×4 = 16,384 values, a factor of 48 fewer values. This is not a claim of exactly 48× fewer FLOPs, memory or time: the denoiser's channels and depth, encoder/decoder cost and implementation all matter.

Compression can discard fine detail; text, geometry and high-frequency textures depend on autoencoder quality. The same pattern appears in current audio and video models, although their tensor shapes and autoencoders differ.
